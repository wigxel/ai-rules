# AI Rules

A collection of reusable AI coding rules and skills for use with AI coding assistants (Cline, opencode, etc.).

## Usage

### Install all rules and skills

```bash
npx skills add wigxel/ai-rules
```

### Structure

- `rules/` — Cline-style `.mdc` rule files for code conventions, patterns, and best practices
- `skills/` — opencode skill directories, each containing a `SKILL.md`
